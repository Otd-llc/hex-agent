Muse Spark Open drives the live Hex Cluster configurator through its public browser API. Code checks grade every finished build. Nothing was trained: the changes below are to the agent's tools, prompt and guards, and to the configurator (One Thousand Drones' work, credited to it). Every number names its suite folder, and all of them are graded by one grader ().
